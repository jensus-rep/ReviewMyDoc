# Neutrale Beispieldokumente

Diese drei Texte sind frei erfunden und enthalten keine Kunden-, Projekt- oder Fachdaten.
Sie zeigen Überschriften, Hervorhebungen, Listen, Tabellen und Zitate im Dokumenteditor.
Die Markdown-Dateien dienen als nachvollziehbare Vorlagen für die lokalen Beispieldokumente;
sie werden nicht automatisch in echte Installationen eingespielt.

- **Gute Notizen, klarer Überblick**: Fließtext, Fett, Kursiv, Zitat und Aufzählung.
- **Ein gemeinsamer Ausflug**: Ablaufplan, Tabelle, nummerierte Liste und Checkliste.
- **Ideen für eine Leseecke**: Vergleichstabelle, kurze Abschnitte und unterschiedliche Textstile.
